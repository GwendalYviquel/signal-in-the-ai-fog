# Stats

Downloads of each episode's MP3, from GitHub releases. Generated by `engine/stats.py` from `data/stats.json` (one snapshot a day): do not edit by hand.

They count the catalog site's player, podcast apps reading the RSS feed (Apple Podcasts, Overcast...) and Spotify's own copy of the file: Spotify downloads each episode once and serves its listeners itself, so Spotify plays are in Spotify for Creators, not here. Checks made while building the podcast add a few downloads to the first episodes.
